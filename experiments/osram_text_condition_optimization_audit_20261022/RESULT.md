## 1. 错误与历史收益在哪里？

Local 指**同一完整 checkpoint 的分类端历史置零输出**：保留原 Local 与 Local Skip，
不重新训练 Local-only，不重新扫描 Memory。置零可能产生分布外输入。
按八率测试槽合并计算 W-F1（不是八个分组 W-F1 的宏平均）；中性标签仍计入 MSE，
极性指标与纠错/致错严格排除 y=0，预测阈值为0。

| 数据集 | 当前/严格过去 Text 条件 | 有效测试槽 / 非中性槽 | Local W-F1 | Full W-F1 | 差值 pp | 纠错 / 致错 |
|---|---|---:|---:|---:|---:|---:|
| MOSI | 当前可见 | 3551 / 3388 | 86.617 | 86.539 | -0.077 | 52 / 52 |
| MOSI | 当前缺失、历史见过 | 1746 / 1686 | 53.823 | 62.344 | +8.522 | 329 / 186 |
| MOSI | 当前缺失、历史未见过 | 191 / 174 | 57.075 | 58.312 | +1.237 | 11 / 11 |
| MOSEI | 当前可见 | 24334 / 19059 | 85.171 | 86.923 | +1.752 | 564 / 264 |
| MOSEI | 当前缺失、历史见过 | 9511 / 7506 | 48.967 | 76.575 | +27.608 | 1991 / 831 |
| MOSEI | 当前缺失、历史未见过 | 3427 / 2507 | 61.239 | 66.490 | +5.251 | 87 / 61 |

整体合并测试槽：MOSI Local75.435→Full77.870 W-F1，纠错392/致错249；
MOSEI Local76.275→Full82.894，纠错2642/致错1156。
这些固定模型响应说明收益主要集中在当前缺 Text、历史见过 Text 的条件，
**不等于证明历史 Text 本身的因果贡献**；两组的当前输入、话语位置、历史长度等

## 2. 配对梯度是否系统性相反？

只使用训练标签，以 eval/dropout-off 排除随机扰动。共享参数均保持原值，
用 autograd.grad 读取梯度，不向 .grad 累积，不构建优化器。

| 数据集 | 配对目标 | 总任务梯度平均余弦 | 总梯度负向对数 | MSE 残差异号对数 | 预测 Jacobian 平均余弦 | Jacobian 负向对数 |
|---|---:|---:|---:|---:|---:|---:|
| MOSI | 64 | 0.426 | 16 | 16 | 0.861 | 0 |
| MOSEI | 64 | 0.584 | 11 | 11 | 0.868 | 0 |

对标量 MSE：`grad(loss)=2*(prediction-y)*grad(prediction)`。
在这批样本中，总任务梯度反向**恰好对应两种预测在相同标签两侧**。
除去这个标量后，总体预测 Jacobian 没有反向样本，不能仅凭负任务梯度余弦
宣称存在竞争性的表征学习。

局部参数组不是全部同向。去除 MSE 残差符号后的 Jacobian 统计：

| 参数组 | MOSI 平均余弦 / 负向对数 | MOSEI 平均余弦 / 负向对数 |
|---|---:|---:|
| Observed Encoder | 0.502 / 0 | 0.411 / 3 |
| Write Key | 0.571 / 0 | 0.783 / 1 |
| Write Value | 0.705 / 0 | 0.796 / 1 |
| Query | 0.547 / 0 | 0.665 / 0 |
| Memory alpha/beta | 0.572 / 6 | 0.817 / 3 |
| Local/Flat/Head | 0.929 / 0 | 0.891 / 0 |
| 共享归一化及其他 Embedding | 0.722 / 0 | 0.837 / 2 |

每率任务梯度的组统计见 `GRADIENT_SUMMARY.csv`；Jacobian 和残差符号交叉统计
见 `completed/VALIDATION.json`，原始逐目标记录留在远程 `GRADIENTS.json`。

## 3. 小步更新是否损害另一条件？

每次从相同原权重开始，仅临时做一步 SGD，固定 LR1e-5，然后同时测两种条件的
同目标训练损失，立即精确恢复全部参数。它不是 Adam 训练，也不是独立目标上的
泛化/迁移实验；不据此声称长期训练将涨分或掉分。

| 数据集 | 更新条件 → 观察条件 | 对方平均 ΔMSE（负为改善） | 改善 / 损害 / 数值中性 |
|---|---|---:|---:|
| MOSI | Text可见 → Text缺失 | -0.024924 | 47 / 17 / 0 |
| MOSI | Text缺失 → Text可见 | -0.024192 | 48 / 16 / 0 |
| MOSEI | Text可见 → Text缺失 | -0.003843 | 53 / 11 / 0 |
| MOSEI | Text缺失 → Text可见 | -0.003833 | 53 / 11 / 0 |

数值中性阈值预先固定为 `1e-6*max(1,abs(原对方MSE))`，未扫描步长或阈值。
MOSI 的16对残差异号样本在两个更新方向都互损；另有1对残差同号样本出现有限步
可见→缺失损害。MOSEI 的11对双向互损也全部来自残差异号样本。
其余多数配对在另一条件下改善，平均 ΔMSE 均为负。
实测最大参数更新/参数范数比：MOSI1.758e-5，MOSEI8.945e-6。

## 验证、失败记录与成本

- 15项本地测试通过，覆盖合法配对、严格过去、无效目标、梯度分组、None/非有限梯度、
  SGD异常恢复、真实小型 Flat backward、Encoder临时包装恢复、原 Skip 单次复用。
- 两个真实 GPU 诊断均完成64对，包含实际 forward/backward/有限更新与恢复。
  两种视图目标前 Memory 的最大绝对误差为0，过去预测最大绝对误差为0。
- 测试重放中同一 Flat 输入重新分类必须逐位复现原输出；原miss0.3预测、ID、标签、
  speaker、availability 再与受保护记录核对，极性一致。
- 原模型最终 digest 保持不变，参数没有累积 .grad，两目录均无新增 .pt 权重。
- 同卡并行的实测总耗时（含数据检查/加载/重放/梯度）：MOSI98.49秒，MOSEI139.71秒。
  不是独占GPU速度基准，未测独占峰值吞吐。
- v1 MOSI完成，但MOSEI的精确读出断言因重算strided Local Skip的1.19e-7舍入差异停止。
  修正为复用原前向真实 Skip 后，v2两数据集统一源码重做。v1日志保留、不混入最终表。
- 配对 Encoder 分开计算过去/当前，避免当前 Text 改变打包矩阵形状而扰动相同历史的
  舍入结果；同一原 Encoder 的历史梯度完整保留，再执行一次原 CHM scan。
  生产模型、普通测试重放和 Missing sampler 均不改。

## 当前判断

1. **不能把 Memory 整体无效当作 MOSI/MOSEI 的结论。**固定模型的历史消融收益
   很不均匀，当前缺Text且历史见过Text时尤其明显；这不是纯来源归因证明。
2. **存在局部互损，但本诊断不支持把普遍、系统性的表征梯度冲突直接认定为瓶颈。**
   总梯度反向在这批样本中完全对应MSE残差异号，多数小步更新还改善另一条件。
3. 暂不据此加梯度冲突模块或改任务损失。本次没有额外训练、调参或测试标签优化。
   一种条件的单目标梯度不能代表整个训练batch或长期训练轨迹，也不能排除其他
   checkpoint、其他样本、随机dropout或跨样本更新中存在干扰。
