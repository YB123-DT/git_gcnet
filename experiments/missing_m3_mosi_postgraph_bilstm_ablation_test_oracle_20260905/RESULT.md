# MOSI Post-graph BiLSTM Branch Ablation

## Question

在当前 Text-anchor Missing-M3、GraphConv2 保持启用的条件下，分别移除 Temporal 或 Speaker 分支的图后 BiLSTM，判断哪一支图后时序建模对 MOSI 有效。

实验仅改变一个分支开关：

- `T-off`: `--postgraph-bilstm-ablation temporal`
- `S-off`: `--postgraph-bilstm-ablation speaker`
- `Control`: 两支 Post-BiLSTM 均启用，直接继承已有结果，不重新训练

共同设置：CMU-MOSI、seeds 66--70、100 epochs、8 个测试 missing rates、`fusion-type=text-anchor-residual`、`representation-type=slot`、`graph-second-layer=graphconv`、`checkpoint-selection=test-oracle`。

> 本结果使用逐 missing rate 的 Test-oracle epoch，仅用于机制诊断，不作为无泄漏正式报告值。

## Conclusion

两支 Post-BiLSTM 都不应删除：

- 移除 Temporal Post-BiLSTM 后总体下降 `0.1871`，且 4/5 seeds 下降；Temporal 图后顺序建模有稳定但较小的正贡献。
- 移除 Speaker Post-BiLSTM 后总体下降 `0.1375`，且 3/5 seeds 下降；Speaker 图后 BiLSTM 的贡献更弱、对 rate 更敏感，但没有形成可接受的总体正向消融。
- S-off 在 0.0、0.2、0.4、0.6 上略升，却在 0.1、0.5、0.7 明显下降，尤其高缺失率 0.7 为 `-0.5089`。这不支持将 Speaker Post-BiLSTM 从主模型中移除。

因此当前模型继续保留 Temporal 与 Speaker 两个 Post-BiLSTM。此前 GraphConv2-off 同样为负，说明 MOSI 的低分不能归因于“图后堆叠过深”这一单点。
