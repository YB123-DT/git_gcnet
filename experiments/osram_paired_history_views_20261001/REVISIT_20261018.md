## 与 Memory 故事的边界

此前 A-only 定位显示，rho0.5 在 Base/Gap 置零的同 checkpoint 读出中
仍有较好分数（57.788 vs Full56.986）。因此改善不能直接宣称是 Memory
学会了保存／读取正确历史，也可能涉及当前表示与决策偏置。置零干预有
分布外风险，上述也不能反过来证明历史无价值。

方向上可将第二项贡献定位为训练阶段对 observation-history 变化的适应，
与因果压缩 Memory 结构互补；但普通双视图 task-only 本身不自动构成充分创新。

唯一建议的下一项（本次不启动）：如果决定回到此方向，在当前锁定 MELD
Flat baseline 上做 rho0.5 task-only 的 seed66 迁移初筛，保持环境、GCNet
missing、lr/wd、训练预算与推理结构不变，同时报告 Random ACC/UA 和六种
Persistent ACC/UA；不同时加入 S/U、InfoNCE 或其他结构。不能预言迁移成功。
