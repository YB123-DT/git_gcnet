不是零分。不将该平均称为原八率 benchmark，也不将跨 rate 重复话语当独立样本。

## 逐率结论及例外

1. 双删在全部七个非空 rate 降低 ACC、提高 CE。ACC 降幅为3.165–12.685 pp。
   其中 rate0.3 从60.870降到50.652；rate0.4 从60.132降到47.446。
   两个指定读出槽中的历史 Text 来源，对这批固定模型目标并非无用。
2. Gap-T←T 的条件作用非常明确。rate0.2，单删 Gap-T←T 的 ACC 不变，
   均为56.634，纠错8/致错8；但 Base←T 被删后，保留 Gap-T←T 的 ACC
   是53.398，同时删则为46.926，即条件增益6.472 pp。
3. 七个 rate 中，Base←T 被删后 Gap-T←T 的 ACC 和 CE 改善均大于其在
   Base←T 保留时的改善。七率描述性平均 CE 改善分别为0.149087和0.032747。
   与 MELD 一样支持条件依赖、可能部分补偿的固定分类器行为；不能据单删
   影响较小，就断言 Gap-T←T 没有任务作用。
4. 不能隐藏例外：rate0.1 删 Base←T 的 ACC 从56.962升到60.759，UA 从
   52.124升到61.174，但 CE 从约0.995升到1.087。该 rate 双删 ACC 降到
   53.797，UA 却升到56.901。其余六个 rate 的双删 UA 均下降。
   所以不能将 ACC、UA、CE 当同一个现象，更不能据此制定标签辅助切换规则。

## 科学解释边界

- 这里删的是联合 Block Write 的 Value 槽位来源读取，不是纯 Text 语义，
  也不是删除全部历史 Text。其他 Gap 的 Text 来源以及所有其他来源仍保留。
- 不动 Local/Skip、Query、共享 Memory 的读写或任何模型参数；只改分类输入。
- 非线性交互有限差分不等于语义因果归因。固定分类器的输入移除可能分布外，
  不能据此声称训练新 Gate 必然改善。
- 虽然本次双删的敏感性大于 MELD 的对应诊断，但样本、标签、模型和特征均不同，
  不是受控跨数据集效应比较。
- 只完成用户要求的有限四条件诊断，不自动扩展到四类、五折、多种子或训练。
