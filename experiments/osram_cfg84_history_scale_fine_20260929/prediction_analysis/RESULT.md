# 现有 216 组预测：纠错、致错及标签辅助可纠正空间

**事后 oracle 诊断，绝不是可部署模型成绩。没有训练、推理或权重加载。**

## 对齐与汇总

原 NPZ 不含 ID。使用与远程 SHA256 一致的原始标签元数据，以及原 EpochSeededSubsetSampler（epoch=0、seed 对应 data_order:CMUMOSI:fold:1:test）重建 conversation-major utterance 顺序。每个 seed 恢复 686 个唯一 ID；216 个标签数组逐项一致。ID 映射保存在 reconstructed_sample_ids.csv，不能把无 ID 的原 NPZ 描述为已经直接存有 ID。

严格排除 label=0；label>0 和 prediction>0 判正类，等于0的预测判负。每单元656条，共24×656=15,744次样本出现。同一utterance跨seed/rate重复，下面计数是出现次数，不是独立样本数。没有跨alpha重复累计 oracle 可纠正样本。

每个seed/rate先单独计算W-F1，再在seed内等权平均rate，最后平均3个seed；SD是seed均值的样本SD。分类组合的空子集记NA，不填0；组合分数先平均该seed非空rate，再平均seed。ALL与ATV覆盖24个单元，其余21个（rate=0没有缺失）。组合分数不是全程缺失实验，也不是七组均值再合成总分。

候选仅为本次fine扫描九个alpha（包括1），不混入粗扫0/.5。所有alpha复算W-F1与原记录吻合、标签/availability相同、预缩放输入与mask哈希相同；216个原NPZ分析前后哈希一致。

## 2–3. 可纠正错误与标签辅助 oracle

构造：原版正确保持原始连续预测；原版错误且候选可纠正时取一个正确候选（按alpha升序确定）；其余保持原预测。W-F1只用符号，不依赖多个正确候选中的选择。没有用标签训练Gate。

原版错误 **3044** 次，可纠正 **150** 次，占错误 **4.928%**。按原rate→seed等权汇总的纠错比例为 **4.764%**；二者分母权重不同。
