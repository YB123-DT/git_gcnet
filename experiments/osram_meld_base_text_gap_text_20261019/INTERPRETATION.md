# Base←T 与 Gap-T←T 的条件作用

INTERNAL DIAGNOSTIC ONLY. MELD seed66；同一原 Flat miss0.3 checkpoint，
原 GCNet exact masks，无训练。仅当前 Text 缺失、严格过去见过 Text 的话语。
不是完整测试集，也不是受保护三种子 baseline 的替代值。

## 描述性汇总

以下是 **0.1–0.7 七个非空 rate 的子集指标等权平均**，不是八率正式成绩，
不是对独立样本的汇总；同一句话可能在多个 rate 重复出现。0.0 没有合格目标。
每个 rate 内四条件严格使用同一批话语，逐率原始表见 RESULT.md。

| 条件 | ACC (%) | UA (%) | W-F1 (%) | CE |
|---|---:|---:|---:|---:|
| 原模型 | 51.122 | 21.384 | 42.290 | 1.434668 |
| 只删 Base←T | 50.356 | 19.035 | 39.694 | 1.450258 |
| 只删 Gap-T←T | 50.259 | 20.012 | 40.602 | 1.436335 |
| 同时删除 | 48.725 | 17.512 | 37.348 | 1.483804 |

## 能确认什么

1. 同时删除在七个非空 rate 都降低 ACC、UA、W-F1，且提高 CE。
   原模型相对于双删的 ACC 优势为 1.298–6.087 pp。
   不能因为某一路单独移除的 ACC 影响小，就说这两处历史来源对当前分类无用。
2. 单删并非一致有害。例如 rate0.1 删 Gap-T←T 的 ACC 从49.351升到50.649，
   但同时删除后降到47.619。rate0.3 删 Base←T 的 ACC 略升0.142 pp，
   但 UA 从23.107降到20.657；指标不应相互替代。
3. Gap-T←T 的作用取决于 Base←T 是否存在。七个 rate 中，保留 Gap-T←T
   在 Base←T 被删时都降低 CE，且其 CE 改善都大于 Base←T 保留时。
   描述性七率平均 CE 改善分别为0.033546和0.001667。
   这符合两条路径存在条件依赖、可能部分补偿的行为，而非独立可相加的作用。
4. 该现象不能证明两项是纯语义冗余、纯Text信息或恢复出的缺失模态。
   删除的是联合写入 Value 槽位来源读值，不是历史 Text 原始观测；其他 Gap
   的 Text 来源、其他来源、Local、Skip、Query 与 Memory 更新始终保留。
5. 这也没有证明应当增加 Gate 或重新加权。它只是固定分类器的移除敏感性，
   输入移除可能离开训练分布；本轮不新增模块、不选新超参数、不扩大训练。

## 验证边界

- 原模型、单删 Base←T、单删 Gap-T←T 在合格样本上逐位复现旧审计缓存。
- 所有未入选样本的四种 logits 完全相同；原模型参数和随机数状态不变。
- 用保存的 logits 独立按 argmax 重算各 rate 的 ACC、纠错/致错，均与报告一致。
- 单 seed、固定原 Test-oracle checkpoint；不作显著性或独立泛化声明。
