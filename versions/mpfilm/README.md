# MPFiLM

`variant.py` implements complete-preserving Missing-Pattern FiLM for both first
RGCN layers. The published default is the Linearized `full` arm; the same file
retains the completed Faithful Edge-wise diagnostic mode.

This route did not produce a stable improvement and is published as a negative
result, not as the final GCNet method.

Results: [`../../results/iemocap6/fold5/mpfilm`](../../results/iemocap6/fold5/mpfilm).
