# Original GCNet — IEMOCAPSix fixed fold 5

This is the inherited Original control used by the paired Sequence-AFF study.
It contains 8 requested missing rates (`0.0` through `0.7`) and 5 seeds
(`66` through `70`), for 40 tasks in total. It is a fixed-fold-5 experiment,
not five-fold cross-validation.

Task-level Original metrics and mask-manifest hashes remain embedded in
[`../sequence_aff/summary.json`](../sequence_aff/summary.json). The compact
summary here avoids duplicating those 40 task records.
