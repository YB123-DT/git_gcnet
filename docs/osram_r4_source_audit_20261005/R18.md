## 论文与代码差异

论文 §3、Eq4 用特权输入控制均值为1的乘性高斯噪声方差；§3.1 Eq8 写对数方差正则，图3/4规定推理关闭 dropout。此处必须区分论文目标与发布代码。

CNN 发布代码实际训练为 `CE(y,pred)+beta*||cat(sigma1,sigma2)||_2`，其中 `sigma=exp(logvar/2)`。它惩罚标准差，不是对数方差，也不是平方 L2；随 batch 和维度改变尺度。`use_l2_sigma_reg` 虽声明但这个损失入口没有判断它。不能把这种作者实现描述成 Eq8 的逐字复现。默认 ReLU logvar >=0，使 sigma>=1；若适配时换成无界线性或 softplus，则需明列机制变化。

## x-star 到底是什么

作者 CNN 的 x-star 是真实 bounding-box 附加标注构造的图像；均值路径看原图。冻结 x-star 卷积梯度或 detach 预提取特征，都不意味着方差网络被冻结。默认共享卷积仍从主路径学习；特权分支仍训练两个 FC 方差头。共享 BatchNorm 的训练统计也可能被额外 x-star 前向更新，即使梯度已切断；OSRAM 迁移不应无意引入这种隐藏状态耦合。

在 OSRAM 中，可以用仅训练期提供的真实完整模态特征作为 x-star，但应明确这比普通 observed-only 训练多用了信息。离线冻结特征向量可作输入，另行学习方差头；把完整 OSRAM 任务表征当 x-star 则需要额外完整前向，可能携带情感监督、历史或状态变化，不能称为“原作者冻结特征方案”。缺失值预测、学生当前 observed 表征或教师预测也不自动等价于真实特权信息。

## 迁移约束与验收条件

建议只在已形成的 observed-only 任务 hidden/readout 上加入乘性噪声；方差头输入为训练数据中真实完整的当前 utterance 特征，和主 Local/Memory 完全分路。不要将完整模态输入替换 node、read_node、write_node、latents、availability；若真实被遮蔽特征进入 Local，或进入 Memory 的值/键/地址，则已经改变缺失协议。detach 只能切断梯度，无法阻止信息泄漏。

现有边界证据：本地 `gcnet_missing_m3/model.py:290–305` 仅投影 valid & available 模态；`osram.py:1547–1557,1580–1599` 区分读节点、写节点、真实模态值并按可用性扫描。x-star 不应绕过这些边界，亦不应使用未来 utterance 或验证/测试特征来估计方差统计。

MOSI MSE 属于任务适配，不能沿用 CE 理论与 beta=100 当作已验证值。实施配置需明确选择“作者代码 std-norm”或“论文 log-variance”目标及归一化；二者不可混称。默认评测应关闭整个特权分支和噪声，返回主路径；running-std 随机评测是另一个可选协议。

后续必验：固定 RNG 的训练噪声公式；方差头与主头梯度可达；padding 无损失贡献；eval 不读 x-star；eval 改变/移除 x-star 时预测相同；改变 unavailable 原始值不改变 Local、Memory、eval 输出；特权分支不会推进主 Memory；保存/恢复噪声 RNG 与必要 running buffers。性能尚未测试。
