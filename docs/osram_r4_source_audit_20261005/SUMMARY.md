# 四项来源核对与迁移边界

本任务仅核对 PDF 和公开代码，不实现模块，不启动实验。已有训练队列不改动。
代码基准：当前 feature/osram-uniform-forced-text；OSRAM 参考
gcnet_missing_m3/osram.py 的 block_write/_scan，原 Flat 完整保留。
这不是性能报告，不能据此宣称解决缺失模态或提升 W-F1。

| 项目 | 保留的核心 | OSRAM 迁移边界 | 核对发现 |
|---|---|---|---|
| R02 DeltaProduct | 一个观测事件内多个非交换 delta/Householder 变换 | 替换状态转移；先用 observed-set 表示产生内部子步骤，不把 A/T/V 任意顺序当时间；沿用先读后写 | 作者语言模型默认写后读；不同入口默认 nh/forget 不同 |
| R03 MesaNet | 累计历史 key/value 充分统计量上的正则最小二乘求解 | 替换 Memory 的内部历史统计，不是仅替换 solve；只用过去真实 observed 特征读取，当前写在读取后 | 公开 FLA kernel 与论文自适应 CG 停止/初始化存在差异 |
| R12 Rank-N-Contrast | 用连续训练标签距离排序表示相似度 | 保持一条因果轨迹；单视图无增强有论文依据；保留原 Flat，任务头不变 | 官方代码是双视图＋两阶段；不能把一阶段 MSE+RNC 叫原始完整复现 |
| R18 LUPI Dropout | 仅训练可用的特权信息生成乘性噪声尺度 | 完整训练特征只进噪声条件分支，不进 Local 输入/Memory 内容；测试不用特权特征，使用固定原文规定的噪声替代 | 论文与作者 CNN 代码正则不同；共享卷积的梯度截止不等于全特权分支冻结 |

## 各自改变什么

- R02/R03 改 Memory 算法，不能宣传为不改 Memory 的轻量读出 Block。
- R12 改表示学习目标；原论文的两阶段训练不满足一阶段偏好，若采用
  一阶段联合监督必须单独记录为迁移版本。SupCR 不与 RNC 合并成一个方法。
- R18 改训练噪声和信息路径；完整训练特征是允许训练信息，不是测试时
  可获得的缺失模态。不得让特权内容进入 persistent Memory，或用测试标签。

## 对此前说明的修正

RNC 官方训练脚本的确用两个 view，但 PDF 附录 G.3 给出单视图、无数据增强
版本，因此“原机制必须双视图”过于绝对。严格区分默认脚本、论文消融和
拟议的一阶段迁移。其他三项也必须区分数学机制和作者具体实现。

## 最小实施范围（尚未授权执行）

若下一步实施，四项独立开关、独立配置；不组合，先各 seed66。保持原数据、
特征、split、availability、task head 和评估口径；必要训练目标/阶段差异明列。
R02必须测试观测集合置换与因果前缀；R03必须对精确小矩阵解作数值对照；
R12须验证距离并列、对角剔除和 valid utterance；R18须验证测试不读取完整
特征及 TRAIN-only 噪声条件路径。均不能让推断的缺失值写入 Memory。
参数量、显存、吞吐均尚未测量，不把理论预估当实测。
