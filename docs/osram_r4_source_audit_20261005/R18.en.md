## Paper versus released implementation

Section 3/Eq4 makes privileged inputs determine variance of mean-one multiplicative Gaussian noise. Eq8 uses log-variance regularization; Figures3/4 disable dropout at inference. These paper choices differ from the released CNN objective.

The actual code minimizes `CE(y,pred)+beta*||cat(sigma1,sigma2)||_2`, with `sigma=exp(logvar/2)`. This is an unsquared standard-deviation norm, not a log-variance norm, and is not normalized by batch size. Declared `use_l2_sigma_reg` is not checked by this loss entry. Default ReLU logvar is nonnegative, hence sigma>=1; changing to unrestricted linear logvar or softplus must be disclosed as adaptation.

## What the privileged input actually represents

Official CNN x-star is an image constructed using actual bounding-box annotations; the main path takes the original image. Stopping x-star convolution gradients or detaching precomputed features does not freeze the learned variance head. Shared convolutions still learn through the main branch, and privileged FC layers remain trainable. Shared training BatchNorm buffers can also update on the extra x-star forward despite gradient blocking; avoid accidentally reproducing this hidden state coupling.

For OSRAM, actual complete training modalities can supply privileged inputs, provided this extra training information is explicitly recorded. Frozen offline feature vectors may feed a trainable variance head. A complete OSRAM task representation instead requires another full forward and can carry task supervision, history, or state mutation; it is not the author's frozen-feature variant. Predicted missing features, student observed representations, and teacher predictions are not automatically equivalent to actual privileged information.

## Adaptation constraints and acceptance checks

Recommended boundary: apply multiplicative noise to an already formed observed-only task hidden/readout, using actual complete current-utterance training features only in a separate variance branch. Never replace node, read_node, write_node, latents, or availability with complete features. Hidden missing values entering Local, or Memory values/keys/addresses, change the missing-data protocol. Detachment blocks gradients, not information leakage.

Local evidence: `gcnet_missing_m3/model.py:290–305` projects only valid & available modalities; `osram.py:1547–1557,1580–1599` separates read/write nodes and actual modality values before availability-aware scanning. Privileged inputs must not bypass those boundaries, use future utterances, or fit statistics on validation/test features.

MOSI MSE is a task adaptation; CE arguments and beta=100 do not establish its correctness. Configuration must choose and name either released std-norm or paper log-variance regularization, including normalization. Default evaluation should skip the entire privileged branch and noise; running-standard-deviation stochastic inference is a separate optional protocol.

Required future checks: training noise matches the fixed-RNG formula; gradients reach both variance and main heads; padding contributes no penalty; eval does not read x-star; changing/removing x-star leaves eval predictions identical; altering unavailable raw values leaves Local, Memory, and eval output unchanged; privileged forwards do not advance main Memory; resume records RNG and applicable running buffers. Performance remains untested.
