## 原始目标与代码对应

设实际参与比较的表示数为 m，标签距离 `d_ij = ||y_i-y_j||_1`，相似度 `s_ij = -||z_i-z_j||_2 / τ`。定义 `S_ij={k : k != i, d_ik >= d_ij}`，则

`L_RNC = [1/(m(m-1))] Σ_i Σ_(j!=i) [-s_ij + log Σ_(k∈S_ij) exp(s_ik)]`。

论文第3–4页 Eq.(1)–(3)。默认双视图 m=2N；附录G.3的单视图/无增强 m=N。

等距离样本共享同一候选集合，会互相出现在分母中；近最优目标鼓励其相似度接近，不要求任意严格次序。最大距离且唯一时分母仅含自己，该项为0。损失是batch内全对关系，不等于一次遍历全训练集。官方实现没有padding/utterance mask、分布式跨卡all-gather或最小batch检查；迁移必须自行处理。其逐j循环每步做 m×(m−1) 操作，直接实现总计算量 O(m³)、主要成对矩阵空间 O(m²)。

## 真实训练配方

论文第3页及附录G.4第22页规定两阶段：先仅用RNC训练encoder，再冻结encoder训练regressor。README L36–45给出 `main_rnc.py` → `main_linear.py --ckpt ...`。

1. `main_rnc.py:72–85/104–131`：train split、shuffle、drop_last，`TwoCropTransform`双独立图像增强；`utils.py:6–11/14–48`是随机crop/flip/color/grayscale。encoder输出无额外projection head（`model.py:146–154`），直接RNC反传，阶段1没有回归loss。
2. 官方AgeDB默认阶段1 400epochs、batch256、SGD lr0.5/weight_decay1e−4/momentum0.9、τ2（`main_rnc.py:22–40`、`utils.py:76–100`）；阶段1最终保存last，入口不跑验证集选encoder（L168–185）。论文附录F第20页说学习率/weight_decay网格搜索，τ搜索后为2；代码默认并不是MOSI可直接套用的最优参数。
3. `main_linear.py:89–115/118–143/185–190`：加载encoder，`model.eval()`+`torch.no_grad()`+detach，优化器只绑定linear regressor，L1训练；默认100epochs、batch64、lr0.05、weight_decay0。这一点与论文附录F笼统batch256存在代码默认差异，需记录。
4. `main_linear.py:62–84/212–237`：train/val/test分离，按val L1最小选regressor，训练结束仅对其测试。不会逐epoch用test选点。

**双视图并非数学上必须**：官方默认入口和 `RnCLoss` 的确硬编码双视图，但论文附录G.3第21页明确研究无增强与单视图增强的N表示RNC，并说明augmentation不是RNC成立的必要条件。不能把“作者默认两视图”误写为“RNC无法单视图”。两阶段仍是原框架，与视图数是两个独立选择。

## OSRAM迁移选择与验收边界

- 建议最先考虑论文已有依据的**单视图、无新增增强、两阶段RNC迁移**：使用当前mask下、严格因果prefix得到的真实utterance表示和原连续MOSI标签。训练batch有效utterance展开后先过滤padding，再建立pair mask；保持已有conversation前向顺序和状态更新，只在loss端跨样本比较。阶段1仅RNC更新encoder；阶段2冻结完整表征路径，训练读出头。该方案无需假设缺失模态或不同历史前缀的表示必须不变，保留RNC实质全对标签距离排序。
- 若用户目标是固定现有cfg84单阶段训练预算，可做 `MSE + λ L_RNC`。必须标记“OSRAM单阶段RNC辅助目标”，并明确它改变阶段结构、目标和梯度；不能声称原作者两阶段复现。λ、τ和表示tap位置按验证集预先固定；不通过test-oracle追调。
- 默认双视图若要迁移，应完整复制同一合法因果prefix和同一observed mask，仅使用有依据的标签保持增强。把不同历史、完整模态/缺失模态或不同missing mask当成零标签距离双视图，会新增跨历史/跨缺失不变性约束，必须单列假设与对照；本轮不默认加入。
- 标签只进入训练loss的距离比较，不进入Memory写入或推理前向；不得把batch标签、未来utterance特征或完整不可见模态传给encoder。val/test不更新参数，不建跨split比较池。跨conversation batch比较是训练监督，不能据此改变因果输入。
- 工程检查：有效样本数<2返回可微零；保留`>=`平局；scalar标签形状一致；padding对数分母全部排除；finite-logsumexp等价实现及极端距离反传；排列不变性；改变masked/future输入不影响当前表示；验证预期encoder/读出冻结与更新。单有效样本双视图无其它实例无法提供有效排序监督，不能算正常batch。

## 审计结论

R12保留，名称只写Rank-N-Contrast。实质区别是按连续标签距离阈值形成每个anchor/target的分母集合，监督batch全对排序；不同于身份InfoNCE或输出ordinal编码。单视图有论文依据，单阶段联合MSE是新迁移设计。尚无本项目实现/性能证据；许可证状态待厘清。
