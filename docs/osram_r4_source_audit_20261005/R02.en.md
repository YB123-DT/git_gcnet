## Formula to actual implementation

H is a key-by-value state. One time step x produces nh independently learned key/value/beta tuples. In fixed slot order j:
`H_j = H_{j-1} + beta_j k_j (v_j - H_{j-1}^T k_j)^T`.
The resulting transition is the ordered product `A=(I-beta_n k_n k_n^T)…(I-beta_1 k_1 k_1^T)`, rather than a sum of rank-one updates. Earlier writes alter later slots' prediction residuals.

## Necessary distinction and defaults

- Preserve nh>1, independent slot projections, ordered updates, and distinct same-token keys. nh=1 reduces to DeltaNet. Repeated identical keys may collapse to one generalized Householder, as discussed on p.5.
- Unit-length keys and beta in [0,1] or [0,2] are needed for the stated factor norm bound; the latter enables reflections. State-tracking experiments use [0,2], but this does not establish that beta>1 is necessary for all tasks.
- Direct layer defaults: nh=2, forget=True, allow_neg_eigval=False, short_conv=True, conv_size=4, head_dim=256, heads=6, expand_v=2, hidden=2048.
- HF configuration instead defaults to nh=1 and forget=False (allow_neg_eigval=False, short_conv=True). Record entry point and effective configuration rather than claiming unspecified author defaults.
- Without short convolution, values use SiLU projections (246–248), an implementation detail beyond the text's linear-value shorthand.
- Output gate/RMSNorm and short convolutions belong to the author macro architecture. Record whether each is retained; they are not the core multiple-Householder mechanism.

## OSRAM transfer boundaries (engineering inference)

1. Reuse permutation-invariant aggregation of visible A/T/V, retaining modality identities and observed masks, then generate ordered internal slots j=1…nh from the same utterance x_t. Internal slot order belongs to the architecture. Direct sequential A→T→V updates generally break set permutation invariance through noncommutativity. A canonical modality ordering only makes storage order irrelevant and requires explicit task semantics.
2. Preserve OSRAM's historical read `read(H_{t-1},q_t)` before writing x_t. Author outputs instead read `H_t^T q_t`; adapting the recurrence requires recording this output-semantic change.
3. For an entirely missing utterance, beta=0; if no-write is required, also set forget gate to one. Padding must prevent decay as well as writes. Reset state per conversation; prevent cross-dialogue/batch leakage.
4. Identify which existing block-delta update is replaced. Multiple beta values or a residual appended after a solve do not establish the ordered Householder product.
5. Mechanism checks: nh=1 matches delta control; slot swaps generally change state; A/T/V storage permutations preserve predictions; missing/padding leave state unchanged; future perturbations leave earlier outputs unchanged; essential projection parameters receive finite gradients.

## Resources and limits

At fixed state dimensions, recurrence work is O(nh·K·V) per utterance and state memory is O(K·V). Each slot adds key/value/beta projections and expands the operator's internal sequence by nh. Page 7 states linear recurrence-training cost growth; Triton pads non-power-of-two head dimensions, weakening speed gains from dimension matching. A small-state PyTorch path is appropriate for initial interface validation; LM-scale throughput/memory findings do not predict GCNet resources.

The source proves expressivity of specific constructions and evaluates formal languages/language modeling. It provides no MOSI, short-conversation, missing-modality, or binary-W-F1 improvement guarantee. A bound on transition matrix norms does not imply universal bounded hidden states, gradients, or optimization. A source-grounded first configuration can explicitly choose nh=2 and [0,2], then use the established validation protocol rather than choosing hyperparameters on test results.
