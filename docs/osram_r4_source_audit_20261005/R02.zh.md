## 公式到真实实现

设状态 H 为 key×value 矩阵；同一时间步 x 生成 nh 套独立可学习的 k_j、v_j、beta_j。按 j 的固定次序：
`H_j = H_{j-1} + beta_j k_j (v_j - H_{j-1}^T k_j)^T`。
这使时间步转移成为顺序乘积 `A=(I-beta_n k_n k_n^T)…(I-beta_1 k_1 k_1^T)`，不是 rank-n 更新求和。前一步写入改变下一步的预测残差。

所有下列路径相对固定作者仓库 commit；可以通过 [pinned source](https://github.com/automl/DeltaProduct/tree/d62241a81d07aa32b1b65e7d17377f6a7cd0a5d8) 复核。

## 必须保留的区别与默认值

- 必须 nh>1，独立 slot 投影，顺序更新，同一步不同 key；nh=1 退化到 DeltaNet。重复同一个 key 的乘积可能退化为单个广义 Householder，第5页解释了此限制。
- 单个因子的 k 需单位范数，beta 范围 [0,1] 或 [0,2]；后者允许反射。原论文 state-tracking 实验用 [0,2]；这不是所有任务都必须 beta>1 的证明。
- 直接 layer 默认：nh=2，forget=True，allow_neg_eigval=False，short_conv=True，conv_size=4，head_dim=256，heads=6，expand_v=2，hidden=2048。
- HF config 默认却是 nh=1、forget=False、allow_neg_eigval=False（仍启用short_conv）。不能宣称“采用作者默认”而不记录入口和最终生效配置。
- value 实现（无短卷积）是 SiLU 投影（246–248），比正文简写的线性 value 多一项非线性。
- 输出 gate/RMSNorm、短卷积属于作者宏架构，可在独立迁移时明列保留/省略；不能把它们当成多 Householder 的核心区别。

## OSRAM 迁移边界（工程推断）

1. 先按现有模态身份和 observed mask 对当前 utterance 的可见 A/T/V 做置换不变汇聚，再由这一 x_t 生成固定内部 slot j=1…nh。slot 顺序是模型结构，不是模态输入顺序。直接 A→T→V 更新通常会因非交换性破坏集合置换不变。固定规范模态排序仅保证存储排列不变，需明确任务定义；本轮首选复用现有集合汇聚。
2. OSRAM 当前读历史需保留 `read(H_{t-1},q_t)` 后才写入当前 x_t。作者 `H_t^T q_t` 是写后读，因此须将 OSRAM 输出语义与来源原输出语义分开记录；可迁移作者更新公式，不能无说明复制 layer 输出。
3. 全缺失 utterance 的 beta=0；若协议要求不写入，则 forget gate 也置1。padding 必须同时阻止更新和衰减；状态按 conversation 重置，不能跨 batch/dialogue 泄漏。
4. 如果复用当前 OSRAM 的 block-delta，则必须检查真正移除/替换哪个更新。多个 beta 或求解后的附加 residual 不足以证明实现了顺序 Householder 乘积。
5. 机制检查应覆盖：nh=1 对齐 delta 对照；交换 slot 导致一般情况下状态变化；A/T/V 存储置换保持预测；全缺失/padding 无状态变化；未来扰动不影响此前输出；关键投影参数能得到有限梯度。

## 资源与限制

固定状态尺寸下，递推每 utterance 成本 O(nh·K·V)，状态 O(K·V)；每个 slot 增加 k/v/beta 投影，算子内部序列长度扩大 nh 倍。作者第7页明确递推训练成本线性增长，Triton 把非二次幂 head dimension 向上 padding 会影响参数匹配的速度收益。现有短 conversation 小状态可先用项目 PyTorch 路径验证；不能照搬 200M–1B LM 的显存或吞吐结果估计 GCNet。

来源只证明其特定模型构造的表达能力并报告形式语言/语言建模实验；不证明 MOSI 短 conversation、缺失模态、binary W-F1 会提高。归一化与 beta 约束约束的是转移矩阵范数，不能泛化成所有隐藏状态、梯度、优化过程有界。要保留机制，优先明确 nh=2 与 [0,2] 的来源选择，再按既有验证协议评估，不以 test 选配置。
